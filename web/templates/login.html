CSCI-531 / Option 2

Privacy-preserving, tamper-evident EHR audit logs.

Every record is encrypted with a fresh AES-256 key, signed with the writer's Ed25519 key, broadcast to three independent storage nodes, and committed only after a 2-of-3 quorum endorses it. No single node can rewrite history.

  • Privacy — AES-GCM payload, RSA-OAEP-wrapped per reader. Doctors write but cannot read.
  • Identification — scrypt password hashing (Postgres), JWT sessions with revocation.
  • Querying — patients see their own records; audit companies see all and can investigate.
  • Immutability — SHA-256 chain hash + Ed25519 actor signature on every block.
  • Decentralization — 3 independent Flask nodes, 2-of-3 quorum.
